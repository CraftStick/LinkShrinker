# Swiss

[English](README.md) · [Русский](README.ru.md)

Swiss: Telegram-бот на Go с набором карманных инструментов: сокращатель ссылок (с HTTP API), информация об IP и домене с картой и WHOIS. Один бинарник, без базы данных. Новые инструменты будут добавляться.

## Возможности

- Сокращает ссылки через HTTP API (`POST /shorten`) или Telegram-бота
- Короткие ссылки перенаправляют кодом `301`
- 6-символьные ID из криптостойкого источника случайности (`crypto/rand`)
- Сокращать ссылки в боте могут только пользователи из белого списка
- Поиск по IP и домену в боте (`/ip`, `/info`) и в инлайн-режиме, доступен всем: точка на карте, страна с флагом, регион, город, индекс, часовой пояс с местным временем, провайдер, организация, AS, имя хоста, признак мобильной сети, WHOIS домена (регистратор, даты, предупреждение об истечении), английский и русский
- Зависимости: [telegram-bot-api](https://github.com/go-telegram-bot-api/telegram-bot-api), `golang.org/x/net` (IDN)

## Запуск

Нужны Go и токен бота от [@BotFather](https://t.me/BotFather).

```bash
git clone https://github.com/CraftStick/LinkShrinker.git
cd LinkShrinker
BOT_TOKEN=123456:ABC... go run .
```

Сервер слушает порт `:8080`.

## Настройки

| Настройка | Где | Описание |
|---|---|---|
| `BOT_TOKEN` | переменная окружения | Токен Telegram-бота |
| `domain` | `main.go` | Публичный адрес для коротких ссылок |
| `allowedUsers` | `main.go` | ID пользователей Telegram, которым разрешён бот |
| `port` | `main.go` | HTTP-порт, по умолчанию `:8080` |

## API

**`POST /shorten`**

```bash
curl -X POST http://localhost:8080/shorten \
  -H 'Content-Type: application/json' \
  -d '{"url": "example.com/very/long/path"}'
```

```json
{"short_url": "https://your-domain/aB3xY9"}
```

Если в ссылке нет `http://` или `https://`, добавляется `http://`.

**`GET /{id}`** перенаправляет на исходную ссылку или возвращает `404`, если ID неизвестен.

## Telegram-бот

Отправьте `/start`, затем любую ссылку: бот ответит короткой (только пользователям из белого списка).

Поиск доступен всем:

- `/ip <адрес>` или `/info <адрес>`: IP, домен или ссылка, в том числе IDN-домены
- Инлайн: напишите `@your_bot 8.8.8.8` в любом чате и выберите карточку или точку на карте
- Геолокация: [ip-api.com](https://ip-api.com) (45 запросов в минуту, остаток берётся из заголовков ответа; 10 оставлено для сообщений в чате), запасной вариант [ipwho.is](https://ipwho.is)
- Домены: RDAP (реестр IANA) с запасным WHOIS по порту 43, поэтому `.ru`, `.рф` и другие национальные зоны работают
- Результаты кэшируются (5 минут для геолокации, 1 час для WHOIS)

Основано на [IPBot-telegram](https://github.com/CraftStick/IPBot-telegram).

## Структура проекта

```
main.go              точка входа: HTTP-сервер и запуск бота
internal/shorten/    сокращатель ссылок: хранилище, HTTP API, редиректы
internal/ipinfo/     поиск по IP и домену, форматирование, точка на карте
internal/whois/      клиент RDAP и WHOIS
internal/i18n/       тексты en/ru и вспомогательные функции
internal/game/       игра «Динозаврик»: HTML-виджет (Bot API 10.4 sendWidget), только личный чат
internal/bot/        Telegram-бот: команды, меню с кнопками, инлайн-режим
```
